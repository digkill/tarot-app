# Tarot — Icon Composer

`Tarot.icon` — редактируемая иконка с эффектами Liquid Glass для iOS 27.
Открыть двойным щелчком в Icon Composer 2.0 или новее.

Сохранены мотивы `../icon.png`: золотой полумесяц, восьмилучевая звезда,
сапфировый центр и тёмно-синий фон. Мелкий орнамент упрощён.
Шесть SVG на холсте 1024 × 1024 собраны в четыре группы с отдельными
настройками материала. В `icon.json` группы и слои перечислены от переднего
плана к заднему. Блики, тени и маску углов создаёт Icon Composer.

Предпросмотры `tarot-ios27-default.png`, `tarot-ios27-dark.png` и
`tarot-ios27-clear.png` экспортированы штатным `ictool` с
`--design-generation 27` (Default, Dark, ClearLight).
PNG — предпросмотры; исходник для интеграции — пакет `Tarot.icon`.

Создано из SVG без генерации растрового изображения.
Конфигурация приложения по-прежнему использует существующую иконку;
новый вариант подготовлен для редактирования в Composer.

Проверено: экспорт всех трёх оформлений в Icon Composer 2.0 (121),
`npx tsc --noEmit`.

Рекомендации Apple: https://developer.apple.com/videos/play/wwdc2026/8012/
